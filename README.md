# CipherTrace

AI-powered Cybercrime Cash Withdrawal Prediction & Intelligence Platform.

## Quick Start (Single Command)

You can start both the **Frontend** and **Backend** together with one command from the root `CipherTrace` folder:

### 1. Install Dependencies (Run Once)
In the root `CipherTrace` folder, run:
```sh
npm install
```

*(Ensure Python dependencies are also installed for the backend if running for the first time: `pip install -r SIH1/SIH/backend/requirements.txt`)*

### 2. Start Both Servers Concurrently
```sh
npm run dev
```

This single command will:
- Automatically activate any Python virtual environment (if present) and launch the Flask backend (`http://localhost:5000`)
- Launch the Vite/React frontend (`http://localhost:8080`)
- Stream prefixed, color-coded console logs: `[BACKEND]` and `[FRONTEND]` in your terminal

## CyberShield AI — Investigating Officer (IO) Module Prototype

This repository includes **CyberShield AI**, an operational decision-support prototype engineered for police Investigating Officers (IOs) handling cyber-fraud cases.

### Core Modules
1. **IO Priority Triage Queue (`/io-dashboard`)**: Prioritizes incoming complaints using an explainable XGBoost-style scoring model with SHAP factor contributions, daily alert budget safeguards, and recovery probabilities.
2. **Investigation Dossier (`/io-complaint/$id`)**: Multi-hop financial trail flowchart (Victim → Mule chain → ATM/POS), live Golden-Hour countdown, spatial ATM cash-out predictions, and Section 65B-compliant digital evidence vault.
3. **Syndicate & Ring Clustering (`/fraud-rings`)**: Automated Disjoint-Set Union (DSU) graph clustering linking disparate cases across state lines into joint FIR dockets.
4. **Statutory Notice Drafter**: Deterministic templates for Section 102 CrPC (Bank Freeze), Section 91 CrPC (CCTV Preservation), and Section 41A CrPC (Lookout Notices).
5. **System & ML Benchmarks (`/metrics`)**: Section 7 architectural targets, ROC-AUC figures, and P95 latency SLAs.

## ⚠ Prototype Notice & Disclaimer

> [!IMPORTANT]
> **DEMO & PROTOTYPE ENVIRONMENT ONLY**
> 1. **Zero Live Government / Bank Connections**: This prototype makes **NO external network requests** to government hosts (`*.gov.in`, `*.i4c.gov.in`, `*.cctns.gov.in`) or production banking switches. All NCRP, CFCFRMS, I4C Suspect Registry, and CCTNS data are served strictly via local client-side synthetic adapters and fixtures (`src/lib/mock-api/`).
> 2. **Deterministic Heuristics, No Autonomous ML Actions**: The priority scorer, ATM location ranker, and fraud ring detectors are deterministic, rule-based heuristics designed to showcase explainability. No models autonomously execute real-world financial or legal actions.
> 3. **Draft Legal Watermark**: All statutory orders and notices generated by the system carry a mandatory `DRAFT` watermark and require formal review, verification, and signature by an authorized officer prior to any real-world service.

## Deploy to Netlify

CipherTrace is configured for seamless deployment on **Netlify** using `@netlify/vite-plugin-tanstack-start`, supporting full Server-Side Rendering (SSR), server functions, and client asset delivery out of the box.

### Configuration Overview
- **Build Command:** `npm run build`
- **Publish Directory:** `dist/client`
- **SSR Serverless Handler:** `.netlify/v1/functions/server.mjs`
- **Configuration File:** [`netlify.toml`](file:///c:/Users/AMAZIAH%20S/Downloads/CipherTrace/netlify.toml)

### Environment Variables
Refer to [`.env.example`](file:///c:/Users/AMAZIAH%20S/Downloads/CipherTrace/.env.example) for available variables. Before your initial deploy, configure any required variables in the Netlify Dashboard:
1. Navigate to **Site settings** → **Environment variables**.
2. Click **Add a variable** and configure:
   - `NODE_ENV`: `production`
   - `VITE_APP_TITLE`: `CipherTrace - CyberShield AI`
   - *(Optional)* `VITE_API_BASE_URL`: URL to external prediction backend if hosted separately.

---

### Deployment Methods

#### Option A: Git-Based Deployment (Recommended)
1. Push your repository to GitHub / GitLab / Bitbucket.
2. In the Netlify dashboard, click **Add new site** → **Import an existing project**.
3. Authorize your git provider and select your repository.
4. Netlify will auto-detect the build settings from `netlify.toml`:
   - **Base directory:** `frontend/cyberguard-insights-main` (or root if deploying standalone)
   - **Build command:** `npm run build`
   - **Publish directory:** `dist/client`
5. Click **Deploy Site**.

#### Option B: Netlify CLI Deployment
1. Ensure the Netlify CLI (v17.31 or newer) is installed:
   ```sh
   npm install -g netlify-cli
   ```
2. Log in to your Netlify account:
   ```sh
   netlify login
   ```
3. Initialize or link your project:
   ```sh
   cd frontend/cyberguard-insights-main
   netlify init
   ```
4. Deploy to production:
   ```sh
   netlify deploy --prod
   ```
